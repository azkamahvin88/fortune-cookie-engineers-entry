One original fortune cookie message for a software engineer:

> You will ask the AI to write the code. The AI will ask you to debug it.

71 characters, one line. The joke is a reversal of the 2026 pair-programming
deal: the engineer delegates the writing to the AI, and the AI hands the
debugging straight back.

## Run it

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The program
validates the line first: exactly one line, 1–120 characters, no control
characters. Python standard library only — no network, no model calls,
no randomness.
